# Unranked-Program
- Is a web application that allows users to book for their child's training time depending on their skill level

# Description
- The focus with the program is touch as many kids lives and impact them through sports and strength training. Building not only Greek Freaks but helping them build mental toughness and resilience, applicable in day to day lives.  

# Features 
- Allows users name,age,skill level and gender
- Views results on allocated training time

# Technologies Used
- HTML
- CSS
- JavaSript

# Setup and Installation
- Git clone the repository: click here to view the website:https://erickochieng-max.github.io/Unranked-Program/
- Open the repository from Ubuntu to VS code 
- Access files on the VS code
- Open the files 
- Open index.html on your browser
